📷 screenshot.js Demo

A drop-in JS utility that adds a screenshot-to-PNG button to any page.

1 — Default: capture the whole page

Just add id="screenshotBtn" to any button. No configuration needed.

<button id="screenshotBtn">Take Screenshot</button>
<script src="screenshot.js"></script>

2 — Custom filename & JPEG format via data attributes

<button id="screenshotBtn"
  data-filename="my-export"
  data-format="jpeg"
  data-quality="0.9">Save as JPEG</button>

3 — Capture a specific element only

<button id="screenshotBtn" data-selector="#capture-target">
  Capture Element
</button>

🎯 This element only

When you click below, only this box is captured — not the whole page.

4 — Programmatic API

Screenshot.capture({
  filename: 'my-page',
  scale: 2,           // retina quality
  format: 'png',
  onDone: (blob) => console.log('Done!', blob)
});
