Deploy Your Own (Recommended)
Public proxies are rate-limited, slow, or go offline. Your own Cloudflare Worker gives you 100,000 requests/day free with no rate limits, global edge locations, and sub-50ms latency worldwide. Takes ~3 minutes to set up.
↗ Open Cloudflare Dashboard
  1. Create a free Cloudflare account at dash.cloudflare.com
  2. Click Open Cloudflare Dashboard above, then Workers & Pages → Create
  3. Choose "Create Worker", give it any name, click Deploy
  4. Click "Edit code", paste the code you copied, click Deploy
  5. Copy your worker URL (like my-proxy.username.workers.dev)
  6. Add it above as a custom proxy: https://my-proxy.username.workers.dev/?url={URL}
  7. Move it to the top of the proxy list using the ▲ arrow

Site Handlers
Some sites (YouTube, Twitter/X) use heavy JavaScript, fingerprint the browser, or tie resources to your IP — they break when proxied. Site handlers automatically redirect to privacy frontends like Invidious and Nitter that serve the same content without those issues. If an instance is slow or down, pick another from the dropdown.
